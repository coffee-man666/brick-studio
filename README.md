# 积木工坊 · Brick Studio

> 运行在浏览器中的 3D 乐高设计软件 —— 在虚拟底板上自由拼搭,实时预览、随时修改,作品自动保存并支持导出分享,把实体积木的搭建乐趣完整搬进数字世界。

## 产品简介

积木工坊是一款纯前端 3D 拼搭应用:打开网页即可在一块 32×32 的标准底板上像玩真积木一样盖房子、搭场景。它完整还原了实体拼搭的核心规则——网格吸附、自动堆叠、支撑检测,同时提供实体积木做不到的能力:一键换色、撤销重做、零件清单统计、作品文件导入导出。

无论你是想在实际拼搭前预演方案的乐高爱好者,还是希望锻炼孩子空间思维的家长,或是需要快速产出 3D 原型的创作者,积木工坊都能让你零门槛上手、几分钟出作品。

## 核心功能

### 🧱 自由拼搭系统
- **32×32 标准底板**:完整还原乐高底板的凸点阵列,点击任意位置即可放置砖块
- **智能网格吸附**:砖块自动对齐凸点网格,横平竖直,无需手动微调
- **自动堆叠**:点击已有砖块的顶面,新砖块自动摞到正确高度,最高可堆 64 板
- **碰撞与支撑检测**:放置位置必须有平整支撑面,悬空或错位会被拒绝,保证作品结构真实合理
- **放置预览(幽灵砖块)**:鼠标悬停实时显示半透明预览——绿色表示可放置,红色表示位置非法,所见即所得

### 📦 丰富的零件库
- **30 种砖型**,分三大类:
  - **砖块**:1×1 至 2×8 共 11 种标准砖(3 板高)
  - **薄板**:1×1 至 6×6 共 12 种(1 板高)
  - **光面板**:1×1 至 2×4 共 7 种(无凸点顶面,用于铺地、装饰)
- **18 种经典乐高配色**:白、灰、黑、红、橙、黄、绿、蓝、紫、粉等,色板实时同步到零件缩略图
- **90° 旋转**:按键或点按钮即可旋转手中砖块,四个方向随心切换

### 🛠 四种编辑工具

| 工具 | 快捷键 | 作用 |
| --- | --- | --- |
| 搭建 | `B` | 在底板或砖块顶面放置新砖块 |
| 擦除 | `E` | 点击移除砖块,右键点击也可快速删除 |
| 填色 | `P` | 不拆不改,一键更换已有砖块颜色 |
| 取样 | `I` | 吸取任意砖块的型号与颜色,直接续建 |

### 📋 零件清单(用料统计)
按「型号 × 颜色」自动汇总整件作品的所有零件及数量,实时统计砖块总数与凸点总数,可直接作为实体复刻的采购清单。

### 💾 作品管理
- **自动保存**:每次操作后自动存入浏览器,关闭重开作品原样恢复
- **导出 / 导入**:一键导出 `.json` 作品文件,分享给他人在其浏览器中导入继续编辑
- **手动保存与清空**:顶栏快捷操作,清空后仍可用撤销找回

### 🎮 专业 3D 编辑体验
- **撤销 / 重做**:支持 80 步操作历史,误操作零成本
- **四种机位一键切换**:等轴、顶视、前视、侧视,相机平滑过渡
- **自由视角**:左键旋转、右键平移、滚轮缩放
- **真实光影**:PBR 材质、实时软阴影、凸点独立建模,质感媲美实体

### ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `B` / `E` / `P` / `I` | 切换 搭建 / 擦除 / 填色 / 取样 工具 |
| `R` | 旋转手中砖块(90°) |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 手动保存 |
| `Delete` | 删除选中砖块 |

应用内还内置操作指南弹窗,随时查阅。

## 技术栈

| 领域 | 技术 |
| --- | --- |
| 框架 | React 19 + TypeScript 5.9 |
| 构建 | Vite 7 |
| 3D 渲染 | Three.js + React Three Fiber + Drei,WebGL 硬件加速 |
| 状态管理 | Zustand(单一数据源,快照式历史记录实现撤销重做) |
| UI | Tailwind CSS 3 + shadcn/ui,深色工作室主题,全中文交互 |

### 技术亮点

- **实例化渲染**:凸点采用实例化绘制,数百砖块依然流畅运行
- **高度图算法**:以"板"为最小高度单位维护全底板高度图,放置合法性判定精确到每个凸点列
- **快照式历史**:Zustand 不可变状态快照,撤销重做可靠且实现简单
- **健壮的序列化**:导入作品文件时逐项校验砖型、颜色与坐标,过滤非法数据
